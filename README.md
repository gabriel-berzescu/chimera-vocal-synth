# Evidence for the jackdaw pull request

Renders and screenshots linked from the pull request that offers a jackdaw to
[CHIMERA](https://github.com/jamesondh/chimera-vocal-synth)'s Bestiary. They are here, on a branch
of a fork, so that they stay out of the project's history.

- `jackdaw.wav`, `jackdaw.png`: `chimera render creature jackdaw` (a held note, the clear tchak, the
  noisy tchak, five calls of chatter) and its spectrogram.
- `tchak.wav`, `tchak.png`, `tchak-noisy.wav`, `tchak-noisy.png`: the two calls alone.
- `gallery-*-before.png`, `gallery-*-after.png`: the Bestiary on upstream main and with the change,
  at 1440 x 900 and at 390 x 844.
- `jackdaw-desktop.png`, `jackdaw-phone.png`: the jackdaw selected.

Everything was rendered by the engine in the pull request's branch. No recording of a bird is here.
